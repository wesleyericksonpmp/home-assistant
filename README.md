# Home Assistant: Blueprints, Dashboards & Snippets

Things I built for my own Home Assistant and cleaned up to share. Each one runs in my house before it lands here.

## Blueprints

Import a blueprint with its button, then create an automation from it in **Settings > Automations & scenes > Blueprints**.

### Automations

| Blueprint | What it does | Import |
|---|---|---|
| [Find My Phone](blueprints/automation/wesleyericksonpmp/find_my_phone.md) | Rings a phone with a repeating critical alert until you tap **Turn Off** on the notification. Clears itself when it stops. | [![Import blueprint](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fgithub.com%2Fwesleyericksonpmp%2Fhome-assistant%2Fblob%2Fmain%2Fblueprints%2Fautomation%2Fwesleyericksonpmp%2Ffind_my_phone.yaml) |

## Updates

Blueprints imported from this repo can be updated in place: open the blueprint's ⋮ menu in Home Assistant and select **Re-import blueprint**. Each blueprint's page has a changelog.

## Issues and ideas

Open an [issue](https://github.com/wesleyericksonpmp/home-assistant/issues) if something does not work or you have an idea. I write about my Home Assistant setup at [pmpmaker.com](https://pmpmaker.com).
